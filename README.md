# Analyse des Ventes de Supermarché 🛒

Ce projet consiste en une analyse exploratoire des données (EDA) d'un dataset de ventes de supermarché en utilisant Python.

##  Objectifs du Projet
Analyser les tendances de ventes par catégorie de produits.
Visualiser les performances des différents magasins.
Identifier les habitudes d'achat des clients.

## Outils Utilisés
Python 3
Pandas (Manipulation des données)
Seaborn / Matplotlib(Visualisation)
Jupyter Notebook**

##  Comment utiliser ce projet ?
1. Cloner le dépôt.
2. Installer les dépendances : `pip install pandas seaborn matplotlib`.
3. Ouvrir `analyse_ventes.ipynb` dans VS Code ou Jupyter.
